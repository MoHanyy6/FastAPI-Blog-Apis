# 🧠 FastAPI Blog API

A clean, modern REST API built with **FastAPI** that powers a simple blog system — complete with user authentication, post creation, and voting system with direction (Like and Remove Like) by direction 1 and 0.
🎥 [Watch Demo Video](https://drive.google.com/file/d/10ddTQdBS9BAwHIekMoJK56w-YR5-ocMx/view?usp=sharing)
It’s lightweight, async-ready, and built to show how to structure a real FastAPI project like a pro.

---

## 🚀 Features

- 🧑‍💻 **User Authentication** (JWT-based login & signup)
- 📰 **Blog Posts** — Create, update, delete, and read posts
- ❤️ **Vote System** — Like/unlike posts
- 🗄️ **PostgreSQL** ready (through SQLAlchemy ORM)
- 🧱 **Modular structure** — separate routers, models, schemas, and utils
- ⚡ **FastAPI best practices** — async endpoints, pydantic validation, and clean responses
